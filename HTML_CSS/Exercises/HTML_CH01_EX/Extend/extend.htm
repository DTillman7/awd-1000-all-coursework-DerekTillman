Principle 3: Understandable


Guideline 3.1 talks about readable content. To ensure that your website content is readable and understandable for all users, including those with cognitive disabilities.


Guideline 3.2 talks about predictable content. To ensure that your website content is predictable and consistent, making it easier for users to navigate and understand.


Guideline 3.3 talks about input assistance. To ensure that your website provides input assistance to users, such as error messages and suggestions for correcting mistakes.
