Working with Positions

Sticky

This is an example of an element with a sticky position. Its position is based on the user's scroll position.

When you using the sticky position, you have to make sure to have a sticky class in your css file. Make sure you have the code right and add it to where you want something to stay on the page without scrolling down.

Relative

This is an example of an element with a relative position. It can move around a little, depending on the viewport, but it is in a position relative to itself.

The values I decided to use was top: 30px and left: 70px. The whole relative box shifted over to where ever I put it and overlaps the other boxes.

Fixed

This is an example of an element with a fixed position. Its position is relative to the viewport.

The values I decided to use was top: 30px, right: 10px. The whole box shifted to whereever I out it whenever I change it. It also overlaps the other boxes as well

Absolute

This is an example of an element with an absolute position. It is similar to the fixed position; however, it is positioned relative to the closest parent element.

The values I used was bottom: 7, right: 7. The whole boxed shifted to where I put it. It'll overlap the other boxes as well if it's in the area.
